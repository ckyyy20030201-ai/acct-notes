## 專案特色：用規則讓 AI 接著寫

這個專案最重要的檔案是 [`CLAUDE.md`](CLAUDE.md)。它規定了：

- **固定的頁面結構**：每篇講義都是「學習目標 → 核心觀念 → 範例演練 → 常見錯誤 → 小測驗 → 重點回顧」
- **命名與放置方式**：`lessons/NN-english-name.html`，並登記在 `data/lessons.js`
- **可用的元件**：分錄表、T 字帳、觀念卡、小測驗等，只能用已定義的 class
- **會計內容規範**：範例公司統一為「小明咖啡」、借貸必須平衡、科目名稱全站一致
- **新增講義的 SOP 與檢查清單**
- **AI 協作紀錄規則**：每次 AI 修改都要記在 [`AI-LOG.md`](AI-LOG.md)

新增一篇講義時，只要對 AI 說「依照 CLAUDE.md 新增一篇講存貨先進先出法的講義」，AI 就能自己決定檔名、套用模板、填好 6 個區塊、登記到目錄，首頁和「上一篇／下一篇」也會自動更新。

## LLM Wiki 架構

本專案參考 Andrej Karpathy 的〈LLM Wiki〉：課程講義放在 `sources/`（原始資料，AI 只讀不改），AI 依 `CLAUDE.md` 把它們「消化」成講義網頁，每次動作都記在 `AI-LOG.md`。支援三種工作流程：**Ingest**（消化一份資料）、**Query**（回答問題並把好答案存回講義）、**Lint**（全站健康檢查）。

> 原始資料是授課老師的講義，PDF 不上傳，只公開索引 [`sources/README.md`](sources/README.md)。

## AI 協作說明

本專案使用 **Claude**（Anthropic，桌面版連結作者電腦中的專案資料夾）協助製作，分工如下：

- **作者負責**：選定網站主題；決定把 AI 使用紀錄寫成專案規則；提供初級會計課程 CH1–CH4 講義作為原始資料；決定是否採用 AI 每次提出的修改建議（例如全站用詞與課程一致、插入「試算表」並重新編號、調整分錄例題接續小明咖啡）；決定課程講義 PDF 不公開；上傳 GitHub 並發布網站。
- **AI 協助**：撰寫 `CLAUDE.md`、網站程式（HTML／CSS／JS）與各篇講義初稿；讀取課程講義並提出修改建議；依規則自我檢查分錄借貸平衡。

AI 寫出的會計內容一律視為草稿，每次修改的內容與作者的檢查結果都記錄在 [`AI-LOG.md`](AI-LOG.md)。
